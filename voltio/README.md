# Voltio Store (frontend demo)
Open `index.html` in a browser, or host the folder free on GitHub Pages or Netlify (drag and drop).

Pages: index, shop, product, cart, checkout, about, contact (with FAQ).
Edit products in `data.js`. Cart and orders are kept in the browser (localStorage). No backend or real payments.
Promo code: VOLT10 (10% off).
